01 · Arquitectura de Servicios

Cinco pilares de ingeniería e infraestructura

Cada servicio responde a operaciones reales en entornos corporativos y hoteleros: redes estables, servidores auditados, correo autenticado y soporte técnico directo.

01 / 05 CONECTIVIDAD & RF
LAN · WAN · UBIQUITI UNIFI

Redes Corporativas & Wi-Fi UniFi

Diseño, provisión y armado integral de redes empresariales. Cableado estructurado, switching, routing, cobertura inalámbrica de alta densidad con Ubiquiti UniFi y gestión técnica directa frente a ISPs ante caídas o ampliaciones de enlace.

Stack & Protocolos
Ubiquiti UniFi Cableado Estructurado Switches & Routers Wi-Fi Alta Densidad Gestión con ISPs
Segmentación de redes para administración, recepción y conectividad de huéspedes.
Diagnóstico físico de bocas de red, enlace entre edificios y estabilización de enlaces ISP.
02 / 05 CORE INFRASTRUCTURE
SERVER · SQL · RDP · PMS

Servidores & Infraestructura Crítica

Administración y recuperación de servidores Windows Server y SQL Server, entornos de Terminal Server / RDP seguro y redes privadas mediante Tailscale o VPN. Soporte sobre sistemas de gestión hotelera PMS Arion / WinPax y ERP Bejerman.

Stack & Sistemas
Windows Server SQL Server Terminal Server / RDP Tailscale / VPN PMS Arion / WinPax ERP Bejerman
Control de permisos, credenciales de acceso remoto y sincronización entre sedes y servidor central.
Recuperación operativa de servicios tras cortes de energía o bloqueos de base de datos.
03 / 05 OPERACIÓN DIARIA
ON-SITE USHUAIA · REMOTO

Soporte IT Corporativo y Hotelero

Atención presencial y remota preventiva y correctiva para puestos de trabajo, recepción y front desk, administración y puntos de venta. Instalación y soporte de impresoras fiscales, comanderas Hasar y terminales POS.

Equipamiento & Puestos
Presencial & Remoto Recepción / Front Impresoras Fiscales Comanderas Hasar Terminales POS
Puesta en marcha de estaciones nuevas, migración de perfiles, periféricos y software de gestión.
Asistencia directa a equipos de administración, reservas y operación hotelera multisede.
04 / 05 RESILIENCIA & CONTINUIDAD
BACKUP HÍBRIDO · AUDITORÍA

Backups, Monitoreo y Continuidad

Automatización de copias de seguridad híbridas (local y nube), auditoría diaria del estado de salud de servidores, almacenamiento y servicios críticos, y recuperación rápida ante incidentes de hardware, sistema o energía.

Controles & Respaldo
Backups Híbridos Local + Nube Auditoría Diaria Salud de Servidores Recuperación Rápida
Verificación periódica de espacio en disco, integridad de copias y estado de servicios SQL/PMS.
Contención preventiva y respuesta técnica ágil para minimizar detenciones operativas.
05 / 05 IDENTIDAD & MENSAJERÍA
M365 · WORKSPACE · DNS

Correo Corporativo, Dominios y Cloud

Migración e implementación de Microsoft 365 y Google Workspace, administración de zonas DNS y subdominios, endurecimiento mediante autenticación SPF / DKIM / DMARC, gestión de cPanel y defensa activa contra phishing y suplantación.

Plataformas & Seguridad
Microsoft 365 Google Workspace DNS & Dominios SPF / DKIM / DMARC cPanel Defensa Antiphishing
Migración ordenada de casillas corporativas sin pérdida de historial ni interrupción operativa.
Configuración de registros DNS para motores de reserva, subdominios y reputación de envío.
